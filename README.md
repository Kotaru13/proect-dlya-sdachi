# Мини-проект: Менеджер задач

Небольшое консольное приложение на Python для ведения списка задач.

## Возможности

- просмотр списка задач;
- добавление новых задач;
- отметка задачи как выполненной;
- удаление задачи;
- сохранение задач в файл `tasks.json`.

## Требования

- Python 3.10+.

## Запуск

```bash
python app.py
```

## Структура проекта

- `app.py` — основной код приложения;
- `tasks.json` — файл хранения задач (создается автоматически при первом сохранении);
- `.gitignore` — исключения для Git.

## Идея для развития

- добавить сроки выполнения;
- добавить приоритеты;
- сделать фильтрацию по статусам.
